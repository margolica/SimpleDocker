# Simple Docker

## Описание проекта

**Simple Bash** — это простой Bash-скрипт, созданный для автоматизации задач, связанных с импортом данных. Проект
помогает упростить обработку файлов, их преобразование и перемещение, а также другие рутинные операции.

## Основные возможности

- Автоматическая обработка входных данных.
- Поддержка различных форматов файлов.
- Логирование операций для удобства отладки.
- Простая настройка и использование.
