# Simple Docker Project

## Описание проекта

Этот проект представляет собой введение в Docker и включает в себя создание и настройку Docker-образов для веб-сервера на базе **nginx** и мини-сервера на **FastCGI**. В рамках проекта изучаются основы работы с Docker, включая создание образов, управление контейнерами, настройку сетей и использование инструментов для проверки безопасности, таких как **Dockle**. Также проект включает работу с **Docker Compose** для управления несколькими контейнерами.

---

## Содержание проекта

1. **Готовый Docker**  
   - Работа с официальным образом **nginx**: загрузка, запуск, настройка портов и проверка работы.
   - Изучение команд Docker: `pull`, `run`, `inspect`, `stop`, `restart`.

2. **Операции с контейнером**  
   - Настройка конфигурации **nginx** внутри контейнера.
   - Экспорт и импорт контейнера.
   - Управление контейнерами и образами.

3. **Мини веб-сервер**  
   - Разработка простого веб-сервера на **C** и **FastCGI**.
   - Настройка **nginx** для проксирования запросов.

4. **Свой Docker**  
   - Создание Docker-образа для мини-сервера.
   - Настройка **nginx** внутри контейнера.
   - Запуск и проверка работы сервера.

5. **Dockle**  
   - Проверка Docker-образа на безопасность с помощью **Dockle**.
   - Исправление ошибок и предупреждений.

6. **Docker Compose**  
   - Настройка и запуск нескольких контейнеров с помощью **Docker Compose**.
   - Проксирование запросов между контейнерами.

---

## Результаты выполнения

### Part 1: Готовый Docker
- Загружен официальный образ **nginx**.
- Проверена работа контейнера на портах 80 и 443.
- Получена информация о контейнере: размер, IP-адрес, замапленные порты.

### Part 2: Операции с контейнером
- Настроен конфигурационный файл **nginx.conf** для отдачи страницы статуса.
- Контейнер экспортирован и импортирован обратно.
- Проверена работа страницы статуса по адресу `localhost:80/status`.

### Part 3: Мини веб-сервер
- Разработан мини-сервер на **C** и **FastCGI**, возвращающий страницу с текстом `Hello World!`.
- Настроен **nginx** для проксирования запросов на порт 8080.

### Part 4: Свой Docker
- Создан Docker-образ для мини-сервера.
- Настро
